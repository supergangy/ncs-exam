# 전산직 문항 블루프린트 — 150문항

칸을 먼저 정하고 채운다. 1회가 잘 나온 이유가 이 순서였다 (`PLAN.md` 4단계).

`검증` 열은 `tools/verify_cs.py` 가 **실행으로 정답을 확정할 수 있는지**를 뜻한다.
전산 전공은 정답이 지문 밖 사실로 정해지므로, 돌려서 확인되는 문항을 앞세운다.

- **실행** — 계산·시뮬레이션으로 정답이 하나로 떨어진다
- **표준** — 표준 문서나 교과서에서 값이 고정된다 (OSI 계층, RFC 포트 번호)
- **개념** — 정의·분류. 검증기가 없으므로 **비중을 낮게 잡는다**

## 합계와 검증 비중

| | 문항 |
|---|---|
| 8과목 합계 | **150** |
| **실행으로 확정** | **약 95 (63%)** |
| 표준 문서 고정 | 약 12 |
| 개념 | 약 43 |

**개념형이 43문항이다.** 검증기가 없으므로 여기서 사실 오류가 날 위험이 가장 크다.
교과서에서 값이 흔들리지 않는 것만 쓰고, 최신 제품·버전별 동작은 다루지 않는다.

## 지키는 선

- **법령 조문은 가상 규정으로.** 조문 번호와 문구를 지어내지 않는다 (`bank/README.md`)
- 문항마다 `tools/verify_cs.py` 에 검증기를 등록한다. 등록하지 않으면 「미검증」으로 보고된다
- 집필 순서는 `PLAYBOOK` 규칙 `1-14` — 발문·선지를 먼저 쓰고 자료를 채운다
