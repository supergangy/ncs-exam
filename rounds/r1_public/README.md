# 제1회 — 범용 공기업 대비

**50문항 / 60분 · 피듈형 · 8영역** · 범용 기관(`○○공사` / `K공사`)

```bash
python tools/selfcheck.py                  # 기본 회차가 r1_public 이다
python build.py --html                     # 고쳐 가며 확인
python build.py                            # 확정 후 PDF
```

**완성.** 문제집 32쪽 / 해설집 25쪽 / 출제 이유서 18쪽.
정답 분포 ①~⑤ 각 10개, 지면 순서 기준 최대 연속 2.

출제 이유서는 2026-08-15에 50문항 전량을 채워 뒤늦게 붙였다. 이 회차는 `why` 필드가
생기기 전에 만들어졌고, 후기 수집기보다도 앞선다. 그래서 `근거` 칸에 후기 건수를 적을 수
없어 **이 회차가 실제로 근거로 삼은 것**(시판본 코퍼스 실측 · 블루프린트)을 적었다.
자세한 사정은 출제 이유서 첫 문항의 `근거` 칸과 `WORKLOG.md` 2026-08-15 항목에 있다.
조판은 평균 채움 83%, 펼침 넘김 0개.
