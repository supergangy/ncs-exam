# 제6회 — 서울교통공사 대비 (10영역 40문항 / 45분)

## 0. 작업 순서 — 실측 먼저, 판단은 사용자가

1. 시행 자료·후기를 모은다
2. **제작 계획서**(이 문서)를 쓴다
3. **사용자 승인** ← 지금 여기
4. 집필 → selfcheck → 감수 → 빌드

---

## 1. 시험 사양 — 후기 빈도가 아니라 시행 자료를 따른다

같은 사양이 **두 회차에서 확인**되었다. 출처는 나라장터(조달 공고)다.

| | 2025. 2. 8.(토) 본사 | 2026. 1. 24.(토) 9호선 |
|---|---|---|
| 문항·시간 | **40문항 / 45분** | **40문항 / 45분** |
| 선지 | 5지선다 | 5지선다 |
| 범위 | NCS 전영역 | NCS 전영역 |
| 대행사 | 휴스테이션 | 휴스테이션 |
| 파본 확인 | 불가 | 가능 |

수정테이프 사용 가능. 30분·10분·5분(이후 OMR 교환 불가)·1분 전 알림.

### 후기 빈도를 그대로 쓰면 안 된다 (2026-08-18 정정)

후기 384건의 **언급 빈도**로는 「80문항 90분」이 45건으로 최다였고
영역은 수리 43% · 의사소통 21% · 문제해결 18%로 보였다.
**둘 다 설계 근거가 못 된다.**

- 문항 수 — 후기의 「80문항」·「193문항」은 인성검사를 포함하거나
  다른 시험을 섞어 적은 것이다. 시행 자료는 두 회차 모두 40문항이다.
- 영역 — 후기 언급은 **기억에 남은 것**이지 출제 비중이 아니다.
  수리가 43%로 보인 것은 어려워서 많이 적었기 때문이다.

> 후기는 **무엇이 나왔나**(소재·유형)에 쓰고,
> **몇 문항 나왔나**(구성)는 시행 자료로 잡는다.

---

## 2. 영역 배분 — 10영역 각 4문항

두 회차 모두 **정확히 각 4문항**이다.

| 영역 | 2025.2.8. | 2026.1.24. |
|---|---|---|
| 의사소통 | 3 + 1 = 4 | 1 + 3 = 4 |
| 수리 | 0 + 4 = 4 | 0 + 4 = 4 |
| 문제해결 | 0 + 4 = 4 | 0 + 4 = 4 |
| 자기개발 | 1 + 3 = 4 | 3 + 1 = 4 |
| 대인관계 | 4 + 0 = 4 | 1 + 3 = 4 |
| 자원관리 | 0 + 4 = 4 | 2 + 2 = 4 |
| 정보 | 3 + 1 = 4 | 1 + 3 = 4 |
| 기술 | 0 + 4 = 4 | 4 + 0 = 4 |
| 조직이해 | 2 + 2 = 4 | 3 + 1 = 4 |
| 직업윤리 | 1 + 3 = 4 | 1 + 3 = 4 |

(앞이 모듈형, 뒤가 피셋형)

### 모듈 대 피셋

| 회차 | 모듈 | 피셋 |
|---|---:|---:|
| 2025.2.8. | 14 (35%) | 26 (65%) |
| 2026.1.24. | 16 (40%) | 24 (60%) |

**모듈 35~40%.** 코레일(피셋 위주)과 성격이 다르다.
모듈은 다시 둘로 갈린다 — 산인공 표준 교재를 그대로 묻는 「산인공 모듈」과,
공문서 규칙·엑셀 함수처럼 실무 지식을 묻는 「응용 모듈」이다.

## 3. 은행의 공백 — 두 영역이 아예 없다

| 영역 | 은행 보유 | 이 회차 필요 |
|---|---:|---:|
| 자기개발능력 | **0** | 4 |
| 대인관계능력 | **0** | 4 |

40문항의 **20%를 새 영역에서** 써야 한다. 나머지 여덟 영역은 은행에 있다
(의사소통 82 · 수리 100 · 문제해결 89 · 자원관리 37 · 정보 32 ·
기술 32 · 조직이해 37 · 직업윤리 31).

## 4. 실제로 나온 주제 — 문항 설계의 뼈대

시행 자료에 출제 주제가 남아 있다. **산인공 표준 교재의 항목을 그대로 묻는다.**

### 산인공 모듈

| 영역 | 주제 |
|---|---|
| 대인관계 | 갈등해결방법 5형(회피·경쟁·수용·타협·통합) · 임파워먼트 장애요인 4차원(개인·대인·관리·조직) · 팔로워십 5형(소외·순응·실무·수동·주도) · 감정은행계좌 저축 5방법 |
| 자기개발 | 자기개발 구성요소 3(자아인식·자기관리·경력개발) |
| 자원관리 | 직접비 대 간접비 · SMART 법칙 |
| 기술 | 하인리히 산업재해 예방 5단계 · 기술선택 우선순위·하향식·벤치마킹 · 산업재해 기본 원인 3(교육적·기술적·작업관리상) |
| 조직이해 | 조직문화 4유형(친화적·진취적·보존적·합리적) · 네트워크 조직 |
| 직업윤리 | 비즈니스 예절(명함·전화·이메일) · 기업윤리 이해관계자별 문제 |

### 응용 모듈

| 영역 | 주제 |
|---|---|
| 의사소통 | 공문서 숫자·날짜·시간·금액 표기 · 항목 구분 기호와 띄우기 · 어휘 구분(늘리다/늘이다, 거치다/걷히다, 걷잡다/겉잡다, 갖은/가진, 겨루다/겨누다) · 외래어 다듬은 말 |
| 자기개발 | 적극행정 유형 · 경력개발 4유형(직선·전문가·나선·전이) |
| 대인관계 | 경청의 유형 |
| 정보 | 엑셀 날짜 함수(EDATE·WORKDAY·DATE) · INDEX·MATCH · 한글 기능(색인·스타일·메일머지·변경내용 추적·배포용 저장) · 메일머지 표시 |

### 피셋 세부 유형 (2026.1.24.)

| 영역 | 유형 |
|---|---|
| 의사소통 | 내용일치 1 · 추리 1 · 연결어 1 |
| 수리 | 매출액 1 · 거리속력시간 1 · 요금에 따른 거리 1 · 시간차이 1 |
| 문제해결 | 조건부합 3 · 날짜 유추 1 |

**피셋이라 해도 「내용일치」가 많다** — 대인관계 3, 직업윤리 3이 전부 내용일치다.
지문을 주고 읽히는 형이지 계산이 아니다.

## 5. 승인이 필요한 것

### (1) 새 두 영역을 어떻게 채우나

자기개발·대인관계가 은행에 없다. 회차 8문항만 쓸지, 은행에도 쌓을지.

### (2) 산인공 모듈을 어디까지 그대로 쓰나

출제 주제가 **표준 교재의 항목 그대로**다(갈등해결 5형 등).
교재 내용을 지문으로 옮기면 문항이 성립하지만, 우리 규율은
「개념 정의형 발문 금지」(SPEC 2절)다. 사례를 주고 유형을 짝짓게 하는
형으로 바꿔야 한다 — 실제 시험도 그렇게 낸다(「예시에서 나타나는 …」).

### (3) 45분 40문항 = 문항당 67.5초

건보(60초)보다 여유가 있다. 지문 길이와 계산량을 그에 맞춘다.
