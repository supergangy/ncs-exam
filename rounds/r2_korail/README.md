# 제2회 — 한국철도공사(코레일) 대비

**NCS 30문항 / 35분 · 의사소통 10 · 수리 10 · 문제해결 10**

실제 코레일 필기는 **NCS 30 + 전공 30 = 60문항 70분**이다. 우리는 NCS만 만든다.
전공(경영학·컴퓨터일반 등)과 철도법령은 대상이 아니다.

```bash
python tools/selfcheck.py --round r2_korail
python build.py --round r2_korail --html     # 고쳐 가며 확인
python build.py --round r2_korail            # 확정 후 PDF
```

## 0. 작업 순서 — 후기 먼저, 판단은 사용자가

```
① 후기를 담는다   「수집기 켜기」 바로가기
② 제작 차수 시작
③ 신뢰도를 먼저 분석한다   python reviews/report.py --consensus 한국철도공사
④ 소재를 확인한다          python reviews/report.py --brief 한국철도공사
⑤ 제작 계획서를 쓴다 (이 문서)
⑥ 계획서를 제시하고 승인을 받는다                    ← 건너뛰지 않는다
⑦ 집필 → selfcheck → 감수 → 확인
```

**소재가 남으면 버리지 않는다.** 후기 336개 중 이번 회차에 쓰는 것은 30개 안팎이다.
나머지 **단일 증언 319개는 3회·4회 소재 풀**로 남긴다.

## 2. 이 회차의 성격 — 세 가지가 코레일답다

### ① 국어 어문 규범이 나온다

사자성어 7건, 속담 2건, 맞춤법 2건, 외래어 표기, 띄어쓰기(`같이`),
한자 매칭(`결제/결재`), 의태어, 접속사 넣기.

후기 표현 그대로 **"공무원 문제 느낌"**. 1회(범용 공기업)에도 건보에도 없던 유형이다.
**코레일 의사소통의 절반 이상이 이쪽이다.**

### ② 모듈 이론이 문제해결에 섞인다

로직트리 5 · SWOT 5 · PEST 2 · JIT 2 · 3C · BCG 매트릭스 · 캐시카우 · 테일러 ·
인간관계론 · 에이전시숍 · 직무기술서 · 카페테리아 복리후생 · 임프로쉐어 ·
표적집단면접법 · 대용승진 · 다면평가.

후기에 **「모듈형 기법 설명 → 답: 로직트리」** 같은 표현이 그대로 있다.
피셋형 자료해석만으로는 코레일색이 안 난다.

### ③ 수리는 중학 수학 색이 강하다

9로 나눈 나머지 3 · 진법 변환 4 · 수열·규칙 다수 · 도형 넓이·둘레 다수 ·
확률(20면체 주사위) · 경우의 수.

건보의 「계산 회피 판단」과 다르다. **순수 계산·규칙 찾기**다.

## 4. 제작 회차

10문항 단위 3차.

| 차수 | 범위 | 영역 | 상태 |
|---|---|---|---|
| 1차 | 01~10 | 의사소통 | **완료** · 무수정 통과 (규칙 `1-2b` 신설) |
| 2차 | 11~20 | 수리 | **완료** · 전수 재계산 후 집필 |
| 3차 | 21~30 | 문제해결 | **완료** · 명제 2문항 전수 탐색 (4,096 · 342 세계) |

30문항 자가검증 **치명 0 / 경고 0**, 정답 분포 ①~⑤ 각 6개, 최대 연속 1.
문제집 12쪽 / 해설집 15쪽, 평균 채움 86% · 성긴 면 0개.

집필 중 잡은 결함 두 갈래.

| 결함 | 조치 |
|---|---|
| 24·25 발문에 `<strong>` | 1회에서 사용자가 지적한 그 결함이다. 발문 볼드를 걷어냈다 |
| 여백 채우기가 모듈 순서를 흩뜨림 (`D50`) | 모듈 5문항(24~28)에 `"movable": False`. 채움률은 86% 그대로 |

각 차수는 **검산 → 집필 → `selfcheck` → 13항목 감수 → 사용자 확인** 순서를 지킨다.
1회 3~5차에서 세 회차 연속 무수정 통과한 규율을 그대로 적용한다.
집필 전에 `docs/PLAYBOOK.md` 의 해당 절을 펼치는 것이 먼저다.

**1차(의사소통)가 이 회차의 승부처다.** 국어 어문 규범 문항은 이 프로젝트에서 처음 만든다.
사자성어·맞춤법·띄어쓰기는 **정답이 규범으로 확정되는 유형**이라 사실 오류가 곧 치명 결함이다.
집필 전에 국립국어원 기준으로 각 항목을 확인하고, 오답 선지도 실제로 틀린 표기인지 검증한다.
