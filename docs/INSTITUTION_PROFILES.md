# 기관별 출제 프로파일

시판 봉투모의고사를 기관별로 묶어 집계한 출제 경향이다. 우리 문항을 특정 기관색에 맞출 때 이 표를 기준으로 삼는다.

수집 총계: **895문항 / 6개 기관 / 20회차**
