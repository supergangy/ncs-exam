### 1-A. 문단배열형 전용 — 연쇄 고리

`D45`가 나온 원인은 명확하다. **단락을 내용 덩어리로만 나누고 순서 근거를 글의 관습에 맡긴 것.**
정의·원인·영향·대책을 각각 한 단락으로 쓰면 원인과 영향을 맞바꿔도 읽힌다. 순서는 내용이 아니라
**표현**으로 고정해야 한다.

| # | 규칙 |
|---|---|
| 1-A-1 | **도입 단락은 지시 표현이 없는 단 하나여야 한다.** 나머지 네 단락의 첫 문장에는 모두 앞을 받는 표현을 넣는다 |
| 1-A-2 | 각 단락의 **끝 문장이 다음 단락의 첫 문장이 받을 말**을 심어 둔다. 끝 문장을 그냥 마무리로 쓰지 않는다 |
| 1-A-3 | 받는 표현이 가리킬 대상은 **글 전체에서 한 단락에만** 있어야 한다. `그 조건` 이 두 단락에서 성립하면 고리가 아니다 |
| 1-A-4 | 고리 넷 가운데 **한둘은 같은 낱말을 되풀이하지 말고 환언**한다. `해가 진 뒤에도 기온이 내려가지 않는다` → `열대야가 길어지면`. 낱말만 훑어 푸는 것을 막는다 |
| 1-A-5 | 오답은 **고리를 깨뜨리는 방식으로** 만들고, 단평에 *어느 고리가 왜 끊기는지* 적는다 |
| 1-A-6 | **선지 다수가 정답과 같은 단락으로 시작하게** 둔다. 도입 단락을 찾는 것만으로 선지가 하나만 남으면 사실상 그 지점에서 문항이 끝난다 |

**자가검증 (필수).** 고리를 선언하고 120가지를 전수 탐색해 유일해임을 확인한다.
`위반 1건뿐인 순서`가 하나라도 나오면 그 고리가 약한 것이므로 문장을 다시 쓴다.

```python
import itertools
P = list("가나다라마")
# 각 단락 첫 문장이 받는 표현 → 그것을 공급하는 단락. None = 지시 표현 없음(도입 가능)
HOOK = {
    "다": None,
    "나": ("다", "‘그 조건은’ — 조건을 예고하는 단락은 (다)뿐"),
    "마": ("나", "‘열대야가 길어지면’ — 해가 진 뒤 기온을 말한 단락은 (나)뿐"),
    "가": ("마", "‘가장 먼저 꼽히는 대책은’ — 대책을 처음 꺼낸 단락은 (마)뿐"),
    "라": ("가", "‘땅을 넓게 쓰지 않아도 되는 ~도’ — 땅 제약을 말한 단락은 (가)뿐"),
}
def violations(order):
    out = []
    if HOOK[order[0]] is not None:
        out.append(f"{order[0]}가 첫머리 — {HOOK[order[0]][1]}")
    for prev, cur in zip(order, order[1:]):
        need = HOOK[cur]
        if need is None:
            out.append(f"({cur})는 도입 단락이므로 ({prev}) 뒤에 올 수 없다")
        elif need[0] != prev:
            out.append(f"({prev}) → ({cur}) — {need[1]}")
    return out

valid = [o for o in itertools.permutations(P) if not violations(o)]
assert len(valid) == 1, f"유일해가 아니다: {valid}"
risky = [o for o in itertools.permutations(P) if len(violations(o)) == 1]
assert not risky, f"고리가 약하다 — 위반 1건뿐인 순서: {risky}"
```

- [ ] 위반 1건뿐인 순서 0개

- [ ] 정답과 같은 단락으로 시작하는 선지가 2개 이상 (1-A-6)

### 4-B. `<보기>` ㄱㄴㄷㄹ 조합형 — 구조적 함정 주의

**참2·거짓2 진리형은 선지를 어떻게 배열해도 최소 2개 판정으로 뚫린다.** 거짓 둘을 걸러내면 참으로만 된 정답 선지가 유일하게 남기 때문이다. `D6` `D17`

| # | 규칙 | 결함 |
|---|---|---|
| 4-7 | **단독 보기 선지를 1개 넣는다**(예 `① ㄱ`). 그러면 최소 3개를 판정해야 확정된다 | `D17` |
| 4-8 | 또는 **참3·거짓1**로 진리값을 바꾼다 | `D17` |
| 4-9 | **계산량이 가장 큰 보기를 건너뛸 수 있는지** 반드시 전수 탐색으로 확인한다 | `D17` |
| 4-10 | 편성 페이스: 50문항당 12~14건. 정보·기술 영역에 집중 배치(시판본 정보 영역은 47%) | `D26` |

**전수 탐색 검증 코드** — 집필 시 반드시 돌린다.
```python
import itertools
L = ['ㄱ','ㄴ','ㄷ','ㄹ']
def minev(chs, truth):
    """chs: 선지별 보기 집합 리스트, truth: {보기: 참거짓}
    반환 (정답위치, 정답 확정에 필요한 최소 판정 개수)"""
    ts = {l for l in truth if truth[l]}
    ans = [i for i, s in enumerate(chs) if s == ts]
    assert len(ans) == 1, f'정답이 유일하지 않다: {ans}'
    for r in range(1, len(L) + 1):
        for sub in itertools.combinations(L, r):
            cand = [i for i, s in enumerate(chs)
                    if all((l in s) == truth[l] for l in sub)]
            if len(cand) == 1 and cand[0] == ans[0]:
                return ans[0] + 1, r
    return ans[0] + 1, len(L)
# 최소 판정 개수가 3 미만이면 선지를 다시 짠다
```

|---|---|---|
| 세트문항 비율 | 28% | **60~65%** |

`python tools/selfcheck.py --round <회차>` 로 실측치와 목표치를 대조한다.

### 자기보고 데이터로 셀 수 있는 것 (`D51`)

`reviews/` 의 필기후기는 **응시자가 스스로 적은 기록**이다. 무엇을 셀 수 있고 무엇을 셀 수
없는지 구별해야 한다.

| 무엇 | 후기로 셀 수 있나 | 근거를 어디서 가져오나 |
|---|---|---|
| **소재·키워드** (사자성어, SWOT, 9로 나눈 나머지…) | **셀 수 있다** | 후기. 몇 명이 독립적으로 같은 말을 했는지가 곧 무게다 |
| **시험 구성** (문항 수, 시험 시간, 과목) | 셀 수 있다 | 후기. 양식에 적는 항목이라 응답률이 높다 |
| **체감 난이도** | 셀 수 있다 | 후기. 다수 비율로 본다 |
| **문항 형식** (`<보기>` 조합형, 세트 비율, 각주) | **셀 수 없다** | **시판본 실측**(`docs/CORPUS_ANALYSIS.md` · `INSTITUTION_PROFILES.md`) |

**응시자는 소재를 적고 형식은 적지 않는다.** 조합형 문항이 SWOT 소재였다면 후기에는
「SWOT」으로만 남는다. 실제로 후기 1,379건 전체에서 ㄱㄴㄷ 표기를 쓴 사람이 **4명뿐**이다.
그러므로 **형식 언급이 0건이라는 사실은 그 형식이 없다는 뜻이 아니다.**

형식 목표는 시판본 실측에서 가져오고, 해당 기관 실측이 없으면 **가장 가까운 기관에서 유추한 뒤
`PROFILE` 주석에 「유추」임을 적는다.** 측정과 유추를 뒤섞지 않는다.

그리고 **목표를 실측치에 맞춰 내리는 것은 미달을 감추는 일이다.** 못 채웠으면 못 채운 대로
남겨 다음 회차에서 채운다.

### 메타 — 반복된 실패의 공통 원인

세 가지가 결함을 재생산했다. 다음 회차에서 특히 경계할 것.

1. **집필 후 검산** → 검산이 통과하도록 문항을 고치게 되고, 그 과정에서 새 결함이 생긴다. **검산 후 집필**로 순서를 뒤집는다. (`D1` `D13` `D14`)
2. **특정 풀이 순서를 가정한 검증** → "이렇게 풀면 다 계산해야 한다"는 확인은 무의미하다. **최악의 경로(어떤 부분집합만으로 답이 확정되는가)를 전수 탐색**한다. (`D6` → `D17` 재발)
3. **규칙을 문서화하지 않은 채 개별 수정** → 같은 결함이 다른 문항에서 되살아난다. (`D3` → `D22` 재발) 이 문서가 그 대책이다.
