# 정답 선지 분포 실측

시판 봉투모의고사의 해설편 정답표를 집계한 결과다.

> **주의 — 이 수치는 설계 기준이 아니라 참고 자료다.**
>
> 집계 대상은 출제기관의 **기출이 아니라 출판사가 만든 모의고사**다. 따라서 아래의 위치 편향(①이 적고 가운데가 많음)은 실제 시험의 배치 관행이 아니라 **교재 집필자의 습관**일 가능성이 크다.
>
> 이를 그대로 재현하면 응시자에게 *"①은 답이 잘 아니다"* 라는 틀린 감각을 길들이게 된다. 우리 시험은 **의도적인 위치 편향을 만들지 않고** 각 8~12개 범위의 자연스러운 변동만 허용한다(`SPEC.md` 8절).


집계 대상: **1,240문항 / 25회차 / 8개 기관**
