## v1.1.0 — 2026-08-07

v1.0.0 을 실제 기기에 깔아 보고서야 드러난 것들을 고쳤다.
**v1.0.0 은 쓰면 안 된다** — 표가 안 나와 78문항을 풀 수 없다.

### 새 기능
- 좌우 스와이프로 이전/다음 문항 (`PageView`)
- 화면 위쪽 문항 번호 띠 — 누르면 이동, 상태를 색으로 (`lib/qnav.dart`)
- 낱개 풀이에서 되돌아가도 채점 상태가 남는다 (전에는 앞으로만)
- 하단 탭에 복습·오답 배지, 홈에 검색 버튼, 진행 중 회차의 남은 시간
- 지난 성적을 눌러 결과를 다시 본다

### 고침 — 문항이 안 보이던 것
- **표 402개가 통째로 안 그려졌다.** `flutter_html` 3.x 는 `<table>` 을 스스로
  그리지 않는다 — `flutter_html_table` 의 `TableHtmlExtension` 을 붙여야 하고,
  없으면 오류 없이 조용히 사라진다. 자료·지문에 표가 있는 78문항이 풀 수 없는 상태였다
- **발문·선지를 정규식으로 벗기고 있었다.** `&lt;보기&gt;` 가 그대로 노출됐고,
  `cm<sup>2</sup>` 가 `cm 2` 가 됐고(값이 바뀐다), 선지 182곳의 밑줄이 사라져
  어문규범 문항이 무엇을 묻는지 알 수 없었다 → `lib/text.dart` · `HtmlText`
- 같은 이중 이스케이프가 웹판 발문·선지단평에도 있어 함께 고쳤다 (`app/app.js`)

### 고침 — 그 밖
- 탭 다섯 개가 부팅 때 숫자에 얼어붙어 있었다 (`IndexedStack` + `const` 목록)
  → `Store` 를 `ChangeNotifier` 로
- 제출 확인창 위에 자동 제출이 겹치면 앱이 멎었다
- 스와이프 중 별표가 옆 문항에 붙었다
- 메모를 한 번 쓰면 지울 길이 없었다
- 깨진 기록을 반만 읽고 덮어써 나머지를 영영 잃었다
- 회차가 사라진 뒤 그 태그로 들어가면 켤 때마다 죽었다
- 백그라운드 6시간 뒤 60분 시험에 「360분 소요」가 찍혔다
- SVG 가 화면 폭에 안 맞았다 · 과목 「전체 풀기」가 맞힌 문제를 다시 냈다

### 빨라짐
- 검색이 글자마다 HTML 3천 번 파싱 → 색인 + 디바운스
- 키워드 화면 13만 회 순회 → 불러올 때 한 번 (`Repo._index`)
- 응시 중 탭마다 기록 전체 재직렬화 → 모아서 저장 (`saveSoon`)
