## v1.2.0 — 2026-08-07

오래 쓰기 위한 것들. 여섯 가지.

### 기록 백업·복원
폰을 바꾸면 푼 기록이 전부 날아가던 것. 설정 › 기록에서 `.json` 한 장으로 내보내고
새 기기에서 불러온다. **통째로 덮어쓴다** — 확인창에 백업과 지금 기록의 건수를
나란히 보여 주고, 덮어쓰기 직전 지금 것을 `ncsbank.v1.prev` 로 남긴다.

`share_plus` 는 내보내기 전용이라 되돌려 받을 길이 없었다 → `file_picker` 를 넣었다.

### 글자 크기
설정에 다섯 단계(0.9 / 1.0 / 1.15 / 1.3 / 1.5). 고르는 즉시 미리보기에 반영된다.
`MediaQuery` 로 걸어 문제·지문·해설(`flutter_html`)까지 함께 커진다.

### 앱 아이콘
Flutter 기본 「F」를 웹판과 같은 도안으로 바꿨다. adaptive 아이콘까지 만들어
Android 8+ 에서 기기 모양대로 깎인다(전에는 정사각이 흰 테두리째 우겨넣어졌다).
`tools/make_icons.py` 가 Pillow 로 그린다 — 손으로 만든 PNG 는 근거가 없다.

### 풀던 자리 이어하기
50문항 세트를 나갔다 오면 1번부터이던 것. `Store.solo` 한 칸에 남기고, 홈에
이어하기 카드를 띄운다. **같은 묶음으로 다시 들어와도** 저장된 순서·채점 상태로 잇는다
(문항 집합으로 견주므로 섞여 들어와도 알아본다). 낱개 1문항은 저장하지 않는다.

### 문항별 소요 시간
`Attempt.ms` 신설. 낱개 풀이에서 쪽이 보인 순간부터 채점까지를 잰다.
**10분을 넘으면 안 센다** — 켜 둔 채 자리를 비운 것이지 푼 것이 아니다.
통계에 평균 풀이 시간 KPI, 과목 줄마다 평균. 회차 응시는 채점 순간이 없어 재지 않는다.

### 목록 필터
과목·직렬 화면 위에 칩 네 개 — 전체 / 안 푼 것 / 틀린 것 / 북마크. 각 칩에 걸리는
문항 수가 함께 나온다. 「이어서 풀기」와 유형별 줄에 같이 걸린다.
세 파일에 복붙돼 있던 「안 푼 것 먼저」 로직을 `lib/pool_filter.dart` 로 모았다.

### 안에서 바뀐 것
- 직렬화를 `lib/backup.dart` 로 뗐다 — Flutter 를 안 써야 `dart run` 으로 검증한다
- `mobile/windows/` 삭제. 안 쓰는 데스크톱 타깃인데 플러그인 심볼릭 링크 때문에
  Windows 개발자 모드 없이는 빌드가 막혔다. 이 앱은 안드로이드 전용이다

커밋은 태그 `v1.2.0` 참조

## v1.1.0 — 2026-08-07

v1.0.0 을 실제 기기에 깔아 보고서야 드러난 것들을 고쳤다.
**v1.0.0 은 쓰면 안 된다** — 표가 안 나와 78문항을 풀 수 없다.

### 새 기능
- 좌우 스와이프로 이전/다음 문항 (`PageView`)
- 화면 위쪽 문항 번호 띠 — 누르면 이동, 상태를 색으로 (`lib/qnav.dart`)
- 낱개 풀이에서 되돌아가도 채점 상태가 남는다 (전에는 앞으로만)
- 하단 탭에 복습·오답 배지, 홈에 검색 버튼, 진행 중 회차의 남은 시간
- 지난 성적을 눌러 결과를 다시 본다

### 고침 — 문항이 안 보이던 것
- **표 402개가 통째로 안 그려졌다.** `flutter_html` 3.x 는 `<table>` 을 스스로
  그리지 않는다 — `flutter_html_table` 의 `TableHtmlExtension` 을 붙여야 하고,
  없으면 오류 없이 조용히 사라진다. 자료·지문에 표가 있는 78문항이 풀 수 없는 상태였다
- **발문·선지를 정규식으로 벗기고 있었다.** `&lt;보기&gt;` 가 그대로 노출됐고,
  `cm<sup>2</sup>` 가 `cm 2` 가 됐고(값이 바뀐다), 선지 182곳의 밑줄이 사라져
  어문규범 문항이 무엇을 묻는지 알 수 없었다 → `lib/text.dart` · `HtmlText`
- 같은 이중 이스케이프가 웹판 발문·선지단평에도 있어 함께 고쳤다 (`app/app.js`)

### 고침 — 그 밖
- 탭 다섯 개가 부팅 때 숫자에 얼어붙어 있었다 (`IndexedStack` + `const` 목록)
  → `Store` 를 `ChangeNotifier` 로
- 제출 확인창 위에 자동 제출이 겹치면 앱이 멎었다
- 스와이프 중 별표가 옆 문항에 붙었다
- 메모를 한 번 쓰면 지울 길이 없었다
- 깨진 기록을 반만 읽고 덮어써 나머지를 영영 잃었다
- 회차가 사라진 뒤 그 태그로 들어가면 켤 때마다 죽었다
- 백그라운드 6시간 뒤 60분 시험에 「360분 소요」가 찍혔다
- SVG 가 화면 폭에 안 맞았다 · 과목 「전체 풀기」가 맞힌 문제를 다시 냈다

### 빨라짐
- 검색이 글자마다 HTML 3천 번 파싱 → 색인 + 디바운스
- 키워드 화면 13만 회 순회 → 불러올 때 한 번 (`Repo._index`)
- 응시 중 탭마다 기록 전체 재직렬화 → 모아서 저장 (`saveSoon`)
