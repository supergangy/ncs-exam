# corpus — 시판 봉투모의고사 분석 파이프라인

시판 교재를 텍스트로 수집해 우리 문항 설계의 기준값을 뽑는 도구다.
분석 결과는 [`../docs/CORPUS_ANALYSIS.md`](../docs/CORPUS_ANALYSIS.md)에 정리돼 있다.

## 저작권 경계 (중요)

| 대상 | 커밋 여부 | 이유 |
|---|---|---|
| `raw/*.txt` — 교재 원문 추출 텍스트 | **제외** | 상용 저작물 본문. `.gitignore`로 차단 |
| `parsed/*.json` — 문항별 발문 원문 포함 | **제외** | 발문이 원문 그대로 들어감 |
| `parsed/발문사전_*.md` | **제외** | 발문 원문 목록 |
| `extract.py`, `analyze.py` | 커밋 | 우리가 작성한 도구 |
| `docs/CORPUS_ANALYSIS.md` | 커밋 | 통계·비율·경향 등 파생 분석 |

원문 데이터는 **로컬에만 둔다.** 다른 컴퓨터에서 이어 작업할 때는 교재 PDF에서 아래 절차로 다시 만들면 된다.

## 사용법

```bash
# 1) PDF → 페이지 덤프
python corpus/extract.py "C:/path/to/모의고사.pdf" corpus/raw/이름.txt

# 2) 회차·문항 분해 + 통계
python corpus/analyze.py corpus/raw/이름.txt --label "라벨" --areas 20,20,20
python corpus/analyze.py corpus/raw/한전.txt --label "한전" \
       --areas 10,10,10,10,10 --names "의사소통,수리,문제해결,자원관리,정보"
```

`--areas`는 영역별 문항 수다. 문항 번호로 영역을 판정하므로 실제 시험 구성과 맞춰야 한다.
(건보 60문항 = `20,20,20` / 한전 50문항 = `10,10,10,10,10`)

## 스캔본 처리

교재 PDF가 스캔본이면 텍스트 레이어가 없다. `extract.py`가 페이지당 평균 300자 미만이면 경고를 낸다.
그 경우 OCR을 먼저 돌린 뒤 **OCR 결과 PDF**를 `extract.py`에 넣는다.

OCR 정확도는 산문 97~99%, **표 안의 숫자는 크게 떨어진다.** 통계 분석에는 지장이 없으나
개별 문항의 수치를 인용할 때는 원본 이미지로 대조해야 한다.

## 구현 메모

- **문항 경계는 최장증가부분수열(LIS)로 복원한다.** 번호를 순차 매칭하면 OCR이 하나만 놓쳐도
  그 뒤가 전부 끊긴다(인식률 19%). LIS로 바꾸면서 88%가 됐다.
- OCR이 꺾쇠를 `〈〉＜＞《》［］`로 흩뿌리므로 `normalize()`에서 전부 `<>`로 접는다.
- 조사·어미 오인식(`을→올/율`, `를→룰/롤`, `절→잘`)은 `fuzzy()`로 흡수한다. 저장이 아니라
  **분류 매칭에만** 적용한다.
- 발문 유형은 `STEM_PATTERNS`의 정규식을 위에서부터 적용한다. 현재 미분류 약 20%.
